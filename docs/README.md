# /docs

Project documentation - planning materials, reference content, and source
material.

## /docs/planning

The source of truth for what is being built and how. AI agents read these files
to understand requirements and constraints before starting work.

- [`architecture.md`](/docs/planning/architecture.md) - how the project is
  structured
- [`features.md`](/docs/planning/features.md) - what it does, for whom, and in
  what order
- [`requirements.md`](/docs/planning/requirements.md) - what it must and must
  not do
- [`technologies.md`](/docs/planning/technologies.md) - tools, materials,
  platforms, and approaches in use

If you are starting from scratch, these files may begin empty and be filled in
through conversation with the AI. See the BUILD mode guidance for how that
works.

## /docs/reference

Supporting material that informs the planning docs but is not itself
authoritative. This includes:

- Data models and schemas
- Notes from early ideation conversations
- Source material: diagrams, images, sketches, research
- Reference documents: specifications, examples, prior art
- Any content that gives context without being a constraint itself

If you are starting a project from an idea rather than a written specification,
use this folder to capture notes as you develop the concept with the AI across
multiple sessions.
